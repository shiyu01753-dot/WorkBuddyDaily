WorkBuddy 每日签到助手首个公开版本。

- 原生高清界面、多尺寸图标与托盘运行。
- 每日定时打开 WorkBuddy 并签到，支持唤醒补签和有限重试。
- 通过腾讯网页关联账号，本机使用 Windows DPAPI 加密保存登录状态。
- 每账号每天只完成一次，支持识别服务端“已签到”回执。
- 时间可编辑，开机启动可选择。

下载 ZIP 后完整解压，运行 WorkBuddyDaily.exe。Windows 10/11，需要 .NET Framework 4.8。

发行包不包含账号、登录令牌、本机设置或运行记录。需要关联自己的账号。目前支持国内版签到；不支持国际版活跃奖励。程序运行时才能执行计划，关机期间不能签到。
